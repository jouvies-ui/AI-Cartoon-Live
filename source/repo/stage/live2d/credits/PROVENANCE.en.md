## Sources

The upstream model files originated in the creator's “DS鲸鱼娘 / DS鼠控版.zip” VTube Studio package by 氵六青 (Bilibili UID 11272072). Andersen216 generated model3.json and an expression manifest, registering eight motions into standard motion groups. The upstream model package did not provide model3.json.

Cubism Core came from https://cubism.live2d.com/sdk-web/cubismcore/live2dcubismcore.min.js. PixiJS and pixi-live2d-display came from npm pixi.js@6.5.10 and pixi-live2d-display@0.4.0. The retained [source.json](source.json) records the exact upstream Git revision.

The character chain is 上善无形's “溟月” → ZipZipPipe's whale-girl maid design → 氵六青's Live2D model. Their profile links are in [AUTHORS.en.md](AUTHORS.en.md).

## Original model notice

The original Chinese notice is retained verbatim in [PROVENANCE.md](PROVENANCE.md). In English, it permits commercial streaming and self-printed material, prohibits any theft or sale, identifies the model as freely shared, and names 氵六青 as model creator. It includes the creator's published support-group contact.

The model author's permission to redistribute does not waive the underlying character's non-commercial and share-alike terms. This distribution therefore uses CC BY-NC-SA 4.0 for artwork. It grants no additional rights.

For rights concerns, report the filename and evidence to the project so the material can be checked and, where appropriate, replaced or removed.
