# Contributing

[简体中文](CONTRIBUTING.zh-CN.md) | [English](CONTRIBUTING.en.md) | [AI-Cartoon-Live](../README.md)

Issues and pull requests are welcome. Describe the trigger, expected and actual behavior, and a redacted reproduction. Run checks appropriate to the change; browser tests are not physical Windows acceptance tests.

Keep upstream copyrights and licenses. Update both language versions and navigation links when editing documentation. New assets need an author, source, permission and hash. Do not commit model caches, installers, logs, personal recordings, keys, cookies or character memory.

`distribution-files.json` is a reviewed release allowlist. Update hashes only after checking content, provenance and permission. Do not bypass it by automatically accepting an entire directory. Large files belong in Releases or pinned downloads, not Git.

Use your own Git identity. New code follows the repository's AGPL-3.0 license; third-party assets keep their existing terms.
