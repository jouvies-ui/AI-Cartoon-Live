# 参与开发

[简体中文](CONTRIBUTING.zh-CN.md) | [English](CONTRIBUTING.en.md) | [AI-Cartoon-Live](../README.md)

欢迎提交问题或 Pull Request。说明触发方式、预期和实际行为，并附脱敏的复现信息。提交之前运行与改动有关的验证，不把浏览器测试当作 Windows 真机验收。

请保留上游版权与许可，修改文档时同步更新中文和英文页面及语言切换链接。新素材必须说明作者、来源、授权和哈希；不要提交模型缓存、安装包、日志、个人录音、密钥、Cookie 或角色记忆。

`distribution-files.json` 是审查后的分发白名单。只有在确认文件内容、来源及授权后才更新哈希；不能通过自动接受全部当前目录内容来绕过它。大文件进入 Release 或按固定源下载，不直接放进 Git。

默认使用开发者自己的 Git 身份。新增代码遵循本仓库的 AGPL-3.0 许可，第三方素材保持原有许可。
